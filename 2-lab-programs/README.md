# 2. Lab Programs (CSA0920)

This folder contains hands-on Java laboratory practical exercises, object-oriented implementations, and multi-threaded benchmarks.

---

### Programs in this directory:
| Source File | Main Class | Topic / Objective |
|---|---|---|
| [`Attendance.java`](./Attendance.java) | `Attendance` | Student attendance tracker and records manager |
| [`LeaderboardDemo.java`](./LeaderboardDemo.java) | `LeaderboardDemo` | Gaming / academic leaderboard sorting & score ranking |
| [`PlaylistBenchmark.java`](./PlaylistBenchmark.java) | `PlaylistBenchmark` | Performance benchmark comparing `LinkedList` vs `ArrayList` |
| [`TicketBenchmark.java`](./TicketBenchmark.java) | `TicketBenchmark` | Multi-threaded movie/transport ticketing concurrency simulator |
| [`Triage.java`](./Triage.java) | `Triage` | Hospital ER patient triage queue using `PriorityQueue` |
| [`task 1.java`](./task%201.java) | `Task01` | Campus Smart-Parking System OO Class design |
