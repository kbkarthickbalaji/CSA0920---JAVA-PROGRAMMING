# 3. Capstone Project (CSA0920)

## Java-Based Privacy-Preserving Federated Medical Image Diagnosis System

This folder contains the complete Capstone Project implementation and presentation for **CSA0920: Programming in Java**.

---

### Project Details:
* **Title:** Java-Based Privacy-Preserving Federated Medical Image Diagnosis System
* **Architecture:** Distributed Federated Learning with FedAvg aggregation across 4 hospital nodes (North, South, East, West)
* **Explainable AI:** Grad-CAM Neural Attention Visualizer
* **Security:** Zero-Knowledge SHA-256 patient privacy hashing and blockchain audit ledger
* **User Interfaces:** Dual UI with Web Dashboard (`http://localhost:8080`) and native Java Swing GUI
